# Investments context

Domain glossary for weak-signal analysis lives in [vml-trends/CONTEXT.md](../vml-trends/CONTEXT.md). Terms specific to this repository:

| Term | Meaning |
| --- | --- |
| Funding event | VC round, M&A, IPO, or grant recognized in a headline |
| Origin group | Reprints of one announcement merged into one event |
| Strong link | Article whose headline contains the topic term (`in_title`) |
| Scan | One term search in a month window; may split or truncate |
| Funding status | overheated, no overheating found in checked scope, or unknown (computed in vml-signals) |
