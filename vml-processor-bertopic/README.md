# VML BERTopic Processor

Process and embed scientific works collected by `vml-crawler-openalex`, then use BERTopic for topic modeling.

The [crawler documentation guide](docs/upstream/vml-crawler-openalex/INDEX.md) contains the imported embedding requirements, BERTopic research, database and Parquet references, abstract reconstruction examples, collection contracts, and domain context.

These documents are an upstream reference snapshot. This project currently contains no processor implementation or runtime setup.
